# Sprint 3.1-C — Correção SPA Routing (Cloudflare Pages)

## Problema
Erro: `Unsafe attempt to load URL ... chrome-error://chromewebdata/`

Causa: Cloudflare Pages não entende rotas SPA (React Router). Rotas como `/login`, `/dashboard` retornam 404 e quebram a app.

---

## Tarefas

### 1. Criar `apps/web/public/_redirects`
Conteúdo:
```
/* /index.html 200
```

### 2. Rebuild
```bash
cd apps/web && npm run build
```

### 3. Verificar
Confirmar que `apps/web/dist/_redirects` existe após o build.

### 4. Redeploy
Push para GitHub ou forçar redeploy manual no dashboard do Cloudflare Pages.

---

## Validação
- [ ] `https://saaspromosinternas.pages.dev/login` carrega diretamente
- [ ] Refresh (F5) em qualquer rota não quebra
- [ ] Erro `chrome-error` desapareceu

---

## Riscos
Se ainda falhar → verificar console do DevTools (F12) por erros JS que podem estar quebrando a app antes mesmo do routing.
